## 🚀 Featured Projects

### 🧠 1. Cognitive Alarm Platform

An AI-powered adaptive intelligent alarm platform that makes users think before dismissing their alarms and learns from their daily wake-up behavior.

The platform transforms the traditional alarm experience into an intelligent wake-up system using cognitive challenges, machine learning, reinforcement learning, and habit tracking.

**Key Features**

- ⏰ Smart and adaptive alarm scheduling
- 🧩 Seven types of cognitive challenges
- 🧠 Machine learning-based difficulty prediction
- 🤖 Reinforcement learning for adaptive difficulty adjustment
- 📊 Habit tracking and productivity insights
- 🔥 Daily streaks and wake-up consistency tracking
- 👤 Role-based access for Users, Wellness Coaches, and Admins
- 📈 Interactive analytics dashboard
- 🔔 In-app notifications
- 📄 PDF and Excel report generation
- 🔐 JWT authentication and password security
- 🐳 Docker-based deployment

**Tech Stack**

`React 19` `Python` `FastAPI` `PostgreSQL` `SQLAlchemy` `scikit-learn` `NumPy` `Pandas` `JWT` `Docker` `Recharts`
